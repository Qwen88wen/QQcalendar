# Flower Images

Place flower images here with the following names:

| File | flower_type | Description |
|------|-------------|-------------|
| `rose.png` | 1 | Pink Rose |
| `tulip.png` | 2 | Tulip |
| `lavender.png` | 3 | Lavender |
| `sakura.png` | 4 | Cherry Blossom |
| `sunflower.png` | 5 | Sunflower |

**Requirements:**
- PNG format with transparent background
- Recommended size: 512x512 or 1024x1024
- Images will be displayed as Billboard sprites (always facing camera)
